# WK3 – Password Cracking

## Networkwalks Cybersecurity Internship

This repository documents practical exercises completed as part of Week 3 of the Networkwalks Cybersecurity Internship.

The lab focuses on password recovery techniques, PDF hash extraction, dictionary-based password attacks, and the use of password-cracking tools within an authorised cybersecurity testing environment.

## Lab Activities

### 1. Password Cracking with JTR (Johnny)

This practical exercise explores the use of John the Ripper through its graphical interface, Johnny.

**Activities completed:**
- Installing and configuring Johnny.
- Extracting password hashes from encrypted PDF documents.
- Preparing and saving hash files.
- Loading password hashes into Johnny.
- Initiating password-cracking attacks.
- Recovering the PDF password.
- Verifying successful password recovery by opening the encrypted PDF.

**Tool used:**
- John the Ripper (Johnny)

### 2. Password Cracking with Networkwalks Tools

This exercise uses the Networkwalks online Hash Calculator and Password Cracker.

**Activities completed:**
- Downloading the encrypted PDF from the lab folder.
- Generating a PDF hash using the Networkwalks Hash Calculator.
- Extracting and copying the generated hash.
- Using the Networkwalks Password Cracker.
- Executing a dictionary-based password attack.
- Monitoring the cracking process.
- Recovering the PDF password.
- Verifying the recovered password by opening the encrypted PDF.

**Tools used:**
- [Networkwalks Hash Calculator](https://networkwalks.com/hash-calculator/)
- Networkwalks Password Cracker

## Learning Objectives

Through these practical exercises, the lab demonstrates:

- Understanding password hash extraction.
- Working with encrypted PDF files.
- Using John the Ripper (Johnny) for password recovery.
- Understanding dictionary-based password attacks.
- Using online hash-generation and password-cracking tools.
- Interpreting password-cracking results.
- Verifying recovered passwords against encrypted files.

## Ethical Considerations

All activities documented in this repository were undertaken within the context of authorised cybersecurity training and controlled lab exercises.

Password-cracking techniques should only be performed on systems, files, and data for which explicit permission has been granted.

## Conclusion

WK3 provided practical exposure to password recovery techniques using both John the Ripper and Networkwalks tools.

The exercises reinforced the relationship between password hashes, dictionary attacks, and password verification while providing hands-on experience with cybersecurity testing tools.
